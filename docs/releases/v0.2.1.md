# Windows helper startup after sign-in

Version 0.2.1 adds an optional Windows startup shortcut so the CYD dashboard helper starts again after a PC restart and sign-in. Previously, a board could remain at `USB waiting` until the helper was started manually.

## Update and enable

This is a Windows launcher update. Existing v0.2.0 firmware remains compatible; no firmware reflash or Bluetooth re-pairing is needed.

Update a clean clone from `main`, or extract the release source ZIP and set up its Python environment as described in the README. Preserve local changes before updating. From the checkout, run:

```powershell
.\Set-USB-HelperStartup.ps1 -Port COM11
```

Replace COM11 with your verified CYD port. Add `-DeviceId` if you already pin the board's identity. The shortcut starts the existing helper at the next sign-in, without administrator access. To start immediately, use `Start-USB-Helper.ps1` as usual. Keep Codex desktop open for live status.

Remove automatic startup with:

```powershell
.\Set-USB-HelperStartup.ps1 -Remove
```

Removal leaves a running helper alone. `Stop-USB-Helper.ps1` stops the current session but does not remove automatic startup. Keep the checkout at its installed path; remove the shortcut before moving it.

## Validation and limits

All 33 existing Python helper tests and isolated Windows shortcut tests passed locally. Shortcut tests cover creation, updating the port and device identity, removal, `-WhatIf`, and invalid parameters without modifying the user's Startup folder. These tests are also included in the Windows CI job.

A real reboot/sign-in has not been tested. Startup begins only after sign-in and does not supervise or restart a helper that crashes later. Existing USB reconnect behavior remains unchanged.
