# Windows helper recovery

Version 0.2.3 reopens a USB connection after eight seconds without board
acknowledgments. It records board startup and reset reasons when available.
A worker stuck in driver or desktop I/O exits after 45 seconds without progress.

The portable Windows x64 ZIP now includes a supervisor, a recovery task installer,
and a setup guide. The supervisor restarts failed workers after two seconds and
honors intentional Stop requests. The Windows task starts it at sign-in without
a run-time limit. Replace older CYD startup methods when enabling this task.

Download CYD-USB-Helper-v0.2.3-windows-x64.zip and follow WINDOWS-HELPER.md inside.
Configure connection.json with your current COM port and board identity.
Existing v0.2.0 dashboard firmware remains compatible.

Validation includes helper regression tests, the packaged executable smoke check,
and a worker-exit recovery test against a connected CYD. USB disconnections at the
hardware or driver level can still interrupt updates while the device is absent.
