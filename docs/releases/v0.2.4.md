# Automatically return to active chats

Version 0.2.4 returns the monitor to page 1 when a followed local chat enters
Working or Needs you. Previously, browsing to a later page could leave active
chats out of sight even though their live statuses were updating correctly.

## Behavior

- A newly discovered Working or Needs you chat also returns the display to page 1.
- Moving from Working to Needs you, or resuming Working, returns to page 1.
- Repeated snapshots in the same state do not interrupt manual browsing.
- Rediscovering the same status after expiry or reconnect does not cause another jump.
- Page 1 prioritizes Needs you, then Working. More than six priority chats spill
  onto subsequent pages; automatic return does not display every active chat at once.
- Idle, Done, Error, Unknown and remote chat updates do not trigger a page return.

## Update

This is a Windows helper update. Existing v0.2.0 dashboard firmware remains
compatible; no firmware flash or Bluetooth re-pairing is required.

Download `CYD-USB-Helper-v0.2.4-windows-x64.zip` and verify it against
`SHA256SUMS.txt`. Stop the current helper, retain its folder as a rollback backup,
and extract the entire new package to a permanent folder. Follow the
[Windows helper guide](../WINDOWS-HELPER.md) to configure the same verified board
identity and recovery startup. Use only one helper/startup method for that board.

Source users: stop the helper, update a clean checkout with `git pull --ff-only`,
then restart using the existing port and optional device identity. Preserve any
local edits before updating. Keep Codex desktop open for live status.

## Verification

Regression tests cover snapshots, metadata patches, new chats, Working/Needs you
transitions, repeated updates, expiry, reconnect and exclusion of remote updates.
The Windows package builder runs help and a read-only desktop smoke check and
excludes private runtime reports from the downloadable ZIP.
